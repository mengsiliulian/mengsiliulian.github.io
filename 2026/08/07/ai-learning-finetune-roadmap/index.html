从"会用"到"会造"：本地部署与微调大模型的进阶学习路线

上一篇路线讲的是”怎么用好别人的大模型”（提示词工程），这篇进阶路线讲”怎么把大模型变成自己的”——本地部署、开源模型、微调训练。需要一定编程基础，但不需要是算法专家。

这条路适合谁

  • 用过 ChatGPT/DeepSeek，想摆脱 API 费用和隐私顾虑
  • 想基于开源模型做自己的专属助手（客服、写作、知识库问答）
  • 程序员，想理解大模型落地工程

前置要求：会 Python 基础（能跑脚本）、了解命令行、有 8GB 以上显存的显卡（没有也能学，用云端或小模型）。

阶段一：本地跑起来（第 1-2 周）

目标：在自己的电脑上运行一个开源大模型。

学什么：

  • 开源模型生态：Llama、Qwen（通义千问）、DeepSeek、Mistral 等，理解”开源权重”和”开源代码”的区别
  • 量化概念：FP16 / INT8 / INT4——同样的模型，量化后体积变小、显存要求降低，精度略有损失
  • 推理工具：Ollama（最简单，一条命令跑模型）、llama.cpp、vLLM（高性能）

练什么：

  • 用 Ollama 跑一个 7B 模型，体验本地对话（本站有专门教程《本地跑大模型是什么体验？普通人也能玩的 Ollama 指南》）
  • 用 API 方式调用本地模型（OpenAI 兼容接口），让程序对接

产出：本地能跑、能调、能接程序。

阶段二：理解模型原理（第 3-4 周）

目标：知道模型内部大致怎么回事，能读懂论文/文档。

学什么：

  • Transformer 架构核心概念：token、注意力机制（Attention）、上下文窗口（本站有《为什么 AI 记不住你说过的话？掰开揉碎聊 token 和上下文窗口》）
  • 训练三阶段：预训练（学语言）、监督微调 SFT（学对话）、对齐（RLHF/DPO，学”做好人”）
  • 推理过程：为什么模型是”预测下一个词”，为什么会有幻觉（本站有《AI 为什么会一本正经地胡说八道？聊聊大模型的幻觉》）

练什么：

  • 用 Hugging Face 加载一个小模型（如 Qwen2.5-0.5B）做文本生成，观察输出
  • 跑一个简单的训练脚本（transformers 库），体验”训练”是怎么回事

产出：能看懂模型卡（Model Card）、能区分”基座模型”和”对话模型”。

阶段三：微调实战（第 5-8 周）

目标：用自己的数据微调一个专属模型。

学什么：

  • 数据准备：整理成”指令-回答”格式（Instruction Tuning），数据质量 > 数据数量
  • LoRA 微调：只训练一小部分参数，消费级显卡也能跑（关键突破），配套工具 PEFT、Q-LoRA
  • 全参微调 vs LoRA 的取舍：效果 vs 成本
  • 评测：怎么判断微调效果（测试集、人工对比、指标）

练什么：

  • 用中文数据集（如 Alpaca 中文版）微调 Qwen2.5-1.5B/7B（LoRA）
  • 收集自己的数据（比如你的文章、你的产品 FAQ），微调一个”懂你”的助手
  • 对比微调前后效果差异

产出：一个跑在自己电脑上、用自己数据微调过的专属模型。

阶段四：工程化落地（第 9 周起，按需）

目标：把模型变成真正能用的产品/服务。

学什么：

  • 推理服务化：vLLM 部署、OpenAI 兼容 API 暴露
  • RAG（检索增强生成）：向量数据库（如 Milvus、Chroma）+ Embedding 模型，让模型基于你的文档回答（解决”模型不知道你的私有知识”问题）
  • Agent 框架：让模型调用工具、执行多步任务（LangChain、LlamaIndex，或各家官方 Agent 方案）
  • 显存优化：量化部署、KV Cache、批处理

练什么：

  • 做一个”文档问答机器人”：把一批 PDF/文档索引进向量库，用本地模型回答
  • 部署一个带 Web 界面的本地助手（Ollama + Open WebUI 是最快路径）

硬件与成本参考

配置 能跑什么 成本
8GB 显存 7B 模型（INT4 量化） 家用显卡
16GB 显存 14B 模型（量化） 中端显卡
24GB 显存 30B 模型（量化） 高端显卡
云端 GPU 70B+ 大模型 按小时计费

跑不起大模型？没关系——小模型的微调、部署、RAG 流程和大模型完全一样，技能可以迁移。

学习资源

  • Hugging Face：模型、数据集、教程一站式（官方文档很全）
  • Ollama 官方文档：本地部署最快上手
  • 各模型官方仓库：Qwen（阿里）、DeepSeek、Llama（Meta）的 GitHub README 都有部署/微调指南
  • B站/知乎教程：搜”LoRA 微调””Qwen 本地部署”有大量实战教程（注意时效，以官方文档为准）

常见坑

  • ❌ 一开始就微调大模型 → 先跑通 1.5B/7B 再升级
  • ❌ 数据没清洗就训练 → 数据里有错别字/重复，模型会学坏
  • ❌ 只看教程不动手 → 本地部署的坑（显存、依赖、版本）只有踩过才知道
  • ❌ 忽略显卡温度/显存溢出 → 训练时盯着 nvidia-smi

这条路走完，你就从”用 AI 的人”变成了”造 AI 的人”。过程中遇到最多的不是算法问题，而是工程问题——这正是本地部署路线的价值所在：它逼着你真正理解模型是怎么工作的。
