常见问题 FAQ：评论、订阅、转载、联系，都在这里

关于本站的一些常见问题，集中回答。有新问题欢迎在文章评论区留言。

一、关于本站

Q：这是一个什么网站？
A：AI 新闻周报博客。每周精选人工智能领域的重要动态（AI 周报），也发布二次元动态、教程、AI 科普、工具推荐、学习路线、游戏杂谈等内容。所有 AI 新闻均以官方一手来源为准，附可核实链接。

Q：内容多久更新一次？
A：AI 周报每周 1-2 期（视行业动态密度而定）；其他分类不定时更新。有新动态会尽快发布。

Q：网站要收费吗？
A：完全免费，无广告、无会员、无任何付费内容。本站是个人兴趣项目，托管在 GitHub Pages 上，成本为零。

二、关于评论

Q：怎么评论？需要注册吗？
A：评论使用 giscus 系统，需要 GitHub 账号（免费注册）。登录 GitHub 后即可在文章下方发表评论，无需注册本站账号。

Q：没有 GitHub 账号能评论吗？
A：目前不能。这是 giscus 的机制——评论数据存储在 GitHub Discussions 里。如果未来有更好的免费评论方案会考虑更换。

Q：评论审核吗？什么时候显示？
A：评论提交后立即显示。站长会不定期查看，广告、人身攻击等不当内容会被删除。

三、关于订阅

Q：怎么订阅更新？
A：本站提供 RSS 订阅源：/atom.xml。用任何 RSS 阅读器（如 Inoreader、Feedly、QQ 邮箱的 RSS 订阅）添加该地址即可，新文章发布后自动推送。

Q：有邮件订阅吗？
A：暂未提供邮件订阅（需要第三方邮件服务）。当前推荐使用 RSS，或直接收藏本站定期访问。

四、关于内容

Q：文章里的 AI 新闻可信吗？
A：AI 周报有严格的编辑准则：每条新闻必须引用官方一手来源（官方博客、官方文档、官方公告），并附可点击链接；拿不到官方来源的传闻一律不收录。其他分类（如教程、科普）是经验总结类内容，涉及具体工具参数、价格、额度时以官方最新信息为准。

Q：为什么有些热点事件没写？
A：因为”宁缺毋滥”——很多网上传得沸沸扬扬的消息，其实找不到官方出处。本站只收录有官方来源可核实的新闻，这是对读者负责。

Q：能转载本站文章吗？
A：可以。本站文章遵循开放转载原则：注明出处（本站名称 + 原文链接）即可，欢迎分享。转载 AI 周报时请保留官方来源链接。

五、关于技术

Q：网站用什么搭的？
A：Hexo 静态博客 + Fluid 主题 + GitHub Pages 免费托管，全程零成本。详见《本站是怎么搭起来的？一文看懂 AI 新闻的技术架构》。

Q：为什么访问速度还行？
A：静态站 + GitHub 全球 CDN，且前端资源全部自托管（不依赖第三方 CDN），国内访问相对稳定。若后续访问不稳，可能考虑绑定自定义域名。

Q：网站会一直免费下去吗？
A：只要 GitHub Pages 服务存在，就会一直免费运营。站长不打算引入广告或收费。

六、联系站长

Q：怎么联系站长？
A：直接在任意文章评论区留言即可，站长会看到。也可以通过 GitHub（mengsiliulian）联系。

Q：有建议或想看的选题？
A：欢迎评论区留言！比如想看某类 AI 工具的测评、某个技术方向的科普、某部作品的二次元动态，都可以提。
