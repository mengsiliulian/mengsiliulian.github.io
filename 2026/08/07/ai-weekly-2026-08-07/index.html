GPT-5.6 迎来更新、GPT Live 语音系统揭秘、OpenAI 携手 APA：8 月 7 日 AI 动态速览

本期为 8 月 3 日 – 8 月 7 日的 AI 动态速览。所有信息均以官方来源为准（官方博客、官方文档、官方工程博客），并附可核实的链接。官方无公开信息的事件，宁缺毋滥。

📰 新闻速览

🤖 1. GPT-5.6 迎来更新：Sol 更可靠、Luna 免费开放

8 月 6 日，OpenAI 官方博客宣布对 GPT-5.6 系列做出两项重要更新——面向付费用户升级 GPT-5.6 Sol，面向免费用户开放 GPT-5.6 Luna。

对 Plus/Pro 用户（GPT-5.6 Sol）：

  • 事实可靠性提升：内部评测显示，在涉及金融、医疗、法律等需要精确细节的问题上，包含至少一个事实错误的回答比 GPT-5.5 Instant 减少了约 68%（Luna 为 62%）
  • 回答更聚焦：减少不必要的格式化和冗余，快速问题给直接答案，复杂任务（多步规划、研究、写作）给完整但重点清晰的回答
  • 新增”思考强度”滑块：Web、移动端、桌面端均可调节 ChatGPT 在回答前投入多少思考，日常问答拉低，规划/研究/写代码拉高
  • Instant 与 Thinking 体验统一：同一个模型同时驱动快速回答和深度推理，切换时不再感觉像换了模型

对免费用户（GPT-5.6 Luna）：

  • Luna 本周起成为 Free/Go 用户的默认模型
  • 下周起提供无限文字聊天（滥用防护措施内）+ 全新的 Think 按钮（需要更深推理时可让模型多想一会）
  • 文件上传、图片等其他工具仍有限额

安全方面：官方同步发布了配套的 system card（PDF），针对未成年用户训练模型避免浪漫角色扮演、年龄限制挑战等，并新增了面向 18 岁以下用户的表现评估。

来源：OpenAI 官方博客（2026-08-06）

🗣️ 2. GPT Live：实时语音系统背后的工程揭秘

8 月 3 日，OpenAI 工程博客发布长文，详解其第三代语音系统 GPT-Live 的架构设计——这是 ChatGPT 语音体验的核心。

关键信息：

  • 全双工语音模型：GPT-Live 的语音模型可以同时听和说，不再需要传统的”回合检测器”（turn detector）。此前系统靠小模型猜测用户是否说完——猜太早会打断用户，猜太晚会显得迟钝
  • 异步委派：需要深度推理或工具调用时，GPT-Live 可无缝调用 GPT-5.5 等前沿模型，同时不打断对话流
  • 架构核心：音频在客户端与语音模型之间的专用”快速通道”上流动；委派、工具调用等应用逻辑走独立的异步 RPC 边界——慢的工具调用不会卡住语音流
  • 实现细节：媒体前端与推理逻辑用 Go 重写；重新设计了有状态推理、动态上下文管理、协议级优化，整个系统在 6 个月内从零建成
  • 应用落地：该架构已支撑 ChatGPT 桌面版”控制你的电脑、协调你的 agents”等新能力

来源：OpenAI 工程博客（2026-08-03）

🧠 3. OpenAI 携手美国心理学会（APA）：青少年 AI 心理健康合作

8 月 6 日，OpenAI 官方宣布与美国心理学会（American Psychological Association，美国领先的心理学科学和专业组织）达成合作，将心理学科学引入青少年 AI 的开发与使用。

合作方向：

  • 支持家长和照护者：与 APA 联合开发面向家庭的资源，帮助家长引导青少年健康使用 AI，识别何时需要成人介入，并强化”AI 是工具、不是人的替代”
  • 支持从业者：为临床医生和学校心理学家开发资源，帮助识别过度依赖、干预不健康的 AI 使用模式
  • 倾听青少年声音：召集青少年、家庭、临床医生等，了解年轻人实际如何使用 AI、现有支持系统的缺口
  • 现有安全基础：OpenAI 与 260 多名心理健康专家合作，训练 ChatGPT 识别痛苦信号、引导寻求现实支持；已扩展本地化危机资源、一键求助热线、休息提醒、家长控制等功能

来源：OpenAI 官方博客（2026-08-06）

🇨🇳 4. DeepSeek API 文档更新：V4-Flash-0731 与 Anthropic 兼容接口

DeepSeek 官方 API 文档（api-docs.deepseek.com）近日更新，两个值得注意的变化：

  • 模型版本更新：deepseek-v4-flash 已更新为 DeepSeek-V4-Flash-0731 版本，调用方法不变，使用 deepseek-v4-flash 即可调用最新版本
  • Anthropic 兼容 API：除 OpenAI 格式外，现支持 Anthropic API 格式访问，base_url 为 https://api.deepseek.com/anthropic，可使用 Anthropic SDK 直接调用
  • Agent 生态接入：官方文档列出 Claude Code、GitHub Copilot、OpenCode 等主流 Agent/编程工具可直接将 DeepSeek 作为后端模型

来源：DeepSeek API 官方文档
