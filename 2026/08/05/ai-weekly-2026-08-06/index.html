📰 产业动态

1. OpenAI 为 GPT-5.6 系列大幅降价（7/30）

OpenAI 官方发布《Advancing the price-performance frontier with GPT-5.6》，宣布将推理效率提升的红利让利给开发者：

  • GPT-5.6 Luna（最快、最实惠型号）：API 价格下调 80%；
  • GPT-5.6 Terra（日常均衡型）：API 价格下调 20%；
  • 上述降价同样反映在 Codex 与 ChatGPT Work 的付费订阅用量计数中；
  • 同时推出 Fast mode（取代原 Priority Processing）：GPT-5.6 Sol 下比 Standard 快 2.5 倍、价格为 2 倍、智能不变，且向后兼容（原 priority 请求会自动使用 Fast mode）。

官方称，Luna 在专业任务（Agents’ Last Exam 基准）上以估计单任务成本较 Fable 5 低近 99% 的表现超越后者；在编码等场景，可将 Plan 交给 Sol、把已明确的实现交给 Luna，从而最大化每一美元的价值。

来源：OpenAI 官方公告
https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/
另见：GPT-5.6 效率工程解读 https://openai.com/index/gpt-5-6-frontier-intelligence-efficiency/

2. DeepSeek API 文档更新：DeepSeek-V4-Flash-0731（本期为文档快照）

DeepSeek 官方 API 文档当前列出 deepseek-v4-flash 与 deepseek-v4-pro 两个模型，其中 deepseek-v4-flash 已更新至 DeepSeek-V4-Flash-0731 版本：

  • 调用方式不变，仍使用 deepseek-v4-flash 即可访问最新版本；
  • API 与 OpenAI/Anthropic 格式兼容，可通过修改配置用 OpenAI/Anthropic SDK 访问；
  • 支持直接接入 Claude Code、GitHub Copilot、OpenCode 等工具做后端模型。

说明：本条以 DeepSeek 官方 API 文档为准。官方暂未发布配套的正式公告/技术报告，故此处仅记录文档可见的信息，不展开二手媒体的性能渲染。
来源：DeepSeek 官方 API 文档
https://api-docs.deepseek.com/
