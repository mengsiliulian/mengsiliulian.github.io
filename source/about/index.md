## 关于

「AI 新闻周报」是一个专注人工智能动态与深度解读的博客。每周精选重要动态，所有信息以**官方来源**为准，并附可核实链接。

本站基于 Hexo + Fluid 主题构建，托管于 GitHub Pages，完全免费、开源、无第三方写作平台依赖。

## 读者（游客）能做什么

- **浏览**所有公开文章
- 在每篇文章底部**发表评论**（通过 giscus / GitHub Discussions，使用你的 GitHub 账号即可，无需邮箱注册）
- 为喜欢的文章**点赞**（浏览器本地记录）
- 通过 **RSS** 订阅本站更新（atom.xml）

## 投稿与交流

本站发文权归站长，暂不开放直接投稿。如果你想分享内容或参与讨论：

- 在文章评论区留言交流
- 通过 GitHub 联系站长

## 本站板块

- **AI 周报**：每周 AI 重要动态，官方一手来源
- **二次元**：ACG 趣闻、新番官宣、趣味合集
- **教程**：博客搭建、AI 工具、实用技能
- **AI 科普**：概念解释、入门指南
- **工具推荐**：免费好用的 AI 工具
- **学习路线**：自学 AI 的路线与资源
- **游戏杂谈**：AI 与游戏话题随笔
- **站务**：本站公告与说明

## 读者须知

- 评论区交流请文明友善，尊重他人
- 转载本站内容请注明出处（本站采用 CC BY-NC-SA 4.0 许可）
- AI 周报类内容以官方发布为准，其他板块为经验分享，请自行甄别

## 技术方案

- 博客框架：Hexo（Node.js 静态站）
- 主题：Fluid
- 托管：GitHub Pages（零服务器成本）
- 评论：giscus（GitHub Discussions）
- 部署：GitHub Actions 自动构建

搭建过程已写成教程，见《十分钟搭建自己的 AI 新闻博客》。
