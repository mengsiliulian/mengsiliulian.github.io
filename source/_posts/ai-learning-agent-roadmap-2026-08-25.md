「Agent」大概是当下 AI 圈出现频率最高的词之一：豆包工作、微软 Aion、各种「自主式 AI」都在朝 Agent 演进。但很多教程一上来就甩一堆框架名，把你绕晕。这篇学习路线把 Agent 开发拆成**四个阶段**，每阶段给你明确目标、学什么、练什么、产出什么。

## 什么是 Agent（一句话）

普通聊天是这样的：你问一句，它答一句。**Agent 是这样的：你给一个目标，它自己拆解步骤、调用工具、不断试错，直到把事办完。** 核心就是从「被动问答」到「主动完成任务」。

## 阶段一：打好语言模型基础（约 1-2 周）

- **目标**：理解大模型能做什么、不能做什么，会写可靠 Prompt。
- **学什么**：Prompt 工程、上下文窗口、Function Calling（函数调用）、结构化输出。
- **练什么**：用对话模型实现「根据用户问题调用一个 API」的小 demo。
- **产出**：一个能调外部函数的基本工具调用脚本。
- **资源建议**：官方 Prompt 指南、各模型 Function Calling 文档。

## 阶段二：掌握「工具调用」与「上下文」（约 2 周）

- **目标**：让 Agent 学会**使用工具**并**记住上下文**。
- **学什么**：Tool Use、Retrieval（检索/RAG）、记忆（Memory）、多轮对话管理。
- **练什么**：做一个「能查知识库并回答」的简单 Agent，或「能读取文件、算数、查天气」的多工具 Agent。
- **产出**：一个集成 2-3 个工具、带简单记忆的 Agent。
- **关键**：这一阶段你接触到的 RAG 会直接解决「Agent 不知道就乱编」的幻觉问题。

## 阶段三：学会「规划」与「自主执行」（约 3-4 周）

- **目标**：让 Agent 真正「拆解目标、自己选步骤、从失败中调整」。
- **学什么**：ReAct 模式、任务分解、子任务调度、自我反思/纠错、循环执行与终止条件。
- **练什么**：做一个「给定一个研究/整理类任务，自动分步完成并输出报告」的 Agent；或「能处理较长工作流、可中断可恢复」的版本。
- **产出**：一个能自主规划并完成多步任务的 Agent 核心。
- **坑**：一定要设「最大步数上限」和「终止条件」，否则 Agent 可能无限循环烧钱耗时。

## 阶段四：工程化与可靠落地（约 2-4 周）

- **目标**：把 Demo 变成能上线、可控、可观测的东西。
- **学什么**：Agent 框架（如 LangGraph、AutoGen 等）、评估（Evaluation）、成本与延迟控制、日志追踪、权限与安全。
- **练什么**：给 Agent 加日志、统计成本、设置权限边界（它只能访问该访问的东西）、做一套「跑得好不好」的评估集。
- **产出**：一个具备基本工程化（日志/评估/安全）的 Agent 应用。

## 常见坑提醒

1. **别迷信框架**：先跑通最小闭环（模型+工具+循环），再考虑上框架，否则被框架绑架。
2. **警惕无限循环**：一定设步数上限、超时和兜底输出。
3. **权限与安全**：Agent 能调用工具/访问数据，务必做权限隔离，别让它碰不该碰的东西（这条在办公场景尤其重要）。
4. **质量评估**：Agent 输出不稳定，别只看「跑通了」，要建立评估集去量化质量。
