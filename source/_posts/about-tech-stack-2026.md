> 这是一篇"站务"向的技术说明：本站（AI 新闻）用什么搭的、怎么做到免费、怎么自动更新、为什么访问快。写给好奇的读者，也写给想自己搭一个同类博客的人。

## 一、整体方案：静态博客 + 免费托管

本站不是传统动态网站（没有服务器、没有数据库），而是**静态博客**：

- **框架**：Hexo（Node.js 写的静态站点生成器），把 Markdown 文章编译成纯 HTML
- **主题**：Fluid（开源主题，简洁、支持暗色模式、移动端适配好）
- **托管**：GitHub Pages（GitHub 免费提供的静态网站托管，域名是 `mengsiliulian.github.io`）
- **成本**：0 元（域名、托管、流量全部免费，无服务器费用）

静态站的好处：没有后端就没有被攻击面，加载快，几乎不会挂；缺点是"动态功能"（评论、统计）要借助第三方服务——下面会讲。

## 二、文章是怎么发布的

本站的发布流程完全自动化：

1. **写作**：每篇文章是一个 Markdown 文件，存放在仓库的 `source/_posts/` 目录
2. **提交**：文件提交到 GitHub 仓库的 `source` 分支
3. **自动构建**：GitHub Actions（GitHub 的免费 CI 服务）检测到提交后，自动运行 Hexo 把文章编译成 HTML
4. **自动部署**：构建产物推送到 `main` 分支，GitHub Pages 立即更新线上网站

从提交到上线，全程约 1 分钟，不需要手动操作任何服务器。

## 三、互动功能是怎么实现的

静态站本身没有后端，互动功能靠第三方服务：

| 功能 | 方案 | 原理 |
|---|---|---|
| 评论 | giscus | 基于 GitHub Discussions，访客用 GitHub 账号登录即可评论，评论数据存在 GitHub 上 |
| 浏览量 | busuanzi（不蒜子） | 免费统计服务，文章页和页脚显示 PV/UV |
| 点赞 | 本地存储 | 纯前端实现，点赞记录存在访客浏览器里（不跨设备） |

## 四、速度与 SEO 优化

- **资源自托管**：jQuery、Bootstrap 等前端库不再从公共 CDN 加载，而是存在本站服务器（GitHub Pages），避免国内访问 CDN 慢或偶尔抽风
- **图片本地化**：文章配图、图标全部放本站，不依赖外链图床
- **SEO 三件套**：`sitemap.xml`（提交搜索引擎）、`robots.txt`（爬虫规则）、`atom.xml`（RSS 订阅源）
- **移动端适配**：Fluid 主题默认响应式，手机浏览体验与电脑一致

## 五、为什么要这么搭

- **省钱**：全程零成本，没有服务器、没有域名费（当前使用 GitHub 免费子域名）
- **稳定**：GitHub 全球 CDN，静态文件几乎不会挂
- **安全**：无后端、无数据库、无用户数据存储，天然免疫大部分攻击
- **可迁移**：所有内容就是 Markdown 文件，随时可以换平台，数据永远在自己手里
